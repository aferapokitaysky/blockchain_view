# Tracefold

Відкритий інструмент для дослідження руху коштів між блокчейн-адресами.

> **Стан проєкту: ранній прототип.** Граф, мітки гаманців, баланси, таблиця транзакцій і сигнали ризику в інтерфейсі — демонстраційні дані. API може на запит отримувати історію Bitcoin через Blockstream Esplora та історію EVM через Blockscout; постійного моніторингу немає. Підтримуються лише Ethereum, Base та Arbitrum One. Санкційні дані й комерційні сервіси перевірки не підключені. Не використовуйте демонстраційні значення для операційних чи комплаєнс-рішень.

**Документація:** [Русский](README.ru.md) · [Українська](README.uk.md) · [English](README.md)

## Про проєкт

Tracefold задуманий як OSINT-інструмент для розслідувань. Аналітик зможе почати з адреси, простежити перекази в підтримуваних мережах, зберегти підстави кожного зв’язку та перевірити сигнали ризику. Алгоритмічну оцінку не слід сприймати як доказ.

Прототип інтерфейсу містить граф потоків, фільтри мереж, таблицю останніх переказів та пояснюваний демонстраційний індекс ризику.

## Принципи

- Для кожної знахідки показувати мережу, адресу, посилання на транзакцію, джерело і час спостереження.
- Відокремлювати спостережувані транзакції від користувацьких міток і гіпотез аналітика.
- Показувати мережу як припущення, яке треба підтвердити: адресу формату EVM можна використовувати в Ethereum, Base, Arbitrum та інших сумісних мережах.
- Називати оцінку індексом ризикової експозиції, а не ймовірністю чи доказом порушення.
- Показувати повноту покриття й актуальність даних; не створювати враження, що відстежуються всі гаманці та мережі.

## Поточний стек

- **Frontend:** React, TypeScript, Vite та Tailwind CSS.
- **API:** локальний сервіс на Rust і Axum.
- **Постійні дані:** PostgreSQL; початкова міграція створює таблиці розслідувань, відстежуваних адрес і сигналів ризику.
- **Кеш і координація:** Redis; API перевіряє його доступність у readiness endpoint.

API підтримує створення й перегляд розслідувань і відстежуваних адрес, ручну синхронізацію історії Bitcoin та вибраних EVM-мереж, а також сигнали ризику від аналітика. Форма гаманця зберігає адреси й запускає синхронізацію на запит; вікно історії показує збережені спостереження та їхнє джерело. Граф, баланси, панель ризику й основна таблиця транзакцій поки використовують демодані. Сигнали ризику зберігають джерело, але не змінюють попередню оцінку. API не має автентифікації та призначений лише для локальної розробки. Постійної синхронізації, санкційного джерела й комерційного сервісу перевірки немає.

- `GET` / `POST` `/api/v1/investigations`
- `GET` / `POST` `/api/v1/investigations/{investigation_id}/addresses`
- `POST` `/api/v1/investigations/{investigation_id}/addresses/{address_id}/sync`
- `GET` `/api/v1/investigations/{investigation_id}/addresses/{address_id}/transfers`
- `GET` / `POST` `/api/v1/investigations/{investigation_id}/addresses/{address_id}/risk-signals`
- `GET` / `PUT` / `DELETE` `/api/v1/investigations/{investigation_id}/addresses/{address_id}/risk-signals/{signal_id}`

## Синхронізація історії транзакцій

Синхронізація історії запускається лише на запит. Для Bitcoin використовується Blockstream Esplora. Для EVM — REST v2 Blockscout: Ethereum (chain ID 1), Base (8453) та Arbitrum One (42161); інші EVM-мережі не підтримуються. Налаштування: `BLOCKSCOUT_BASE_URL` (типове значення `https://api.blockscout.com`) та необов’язковий `BLOCKSCOUT_API_KEY` (передається як bearer-токен; доступ постачальника може вимагати ключ). Секрети в репозиторії не зберігаються.

Синхронізація Bitcoin зберігає попередню обмежену поведінку Esplora. Для EVM паралельно завантажуються звичайні нативні транзакції, успішні внутрішні перекази нативної валюти та події ERC-20. Зберігаються цілі початкові суми, адреса контракту й необов’язкова кількість decimals, індекс події, адреси сторін, блок, час і хост джерела. Кожен потік EVM обмежено 10 сторінками по 50 записів; `may_have_more_history` показує, що на межі ліміту у постачальника була наступна сторінка. Це історія на запит, а не повний індекс: інші мережі, стандарти токенів і пропуски постачальника не охоплюються. Кілька подій однієї транзакції зберігаються окремо. Endpoint переказів повертає до 500 останніх записів; фонового опитування немає.

## Запуск локального API

Потрібен Docker Compose.

```sh
docker compose --env-file .env.example up --build -d
```

Приклад конфігурації використовує облікові дані лише для локальної розробки. Compose публікує сервіси на loopback; не відкривайте цей API без автентифікації в мережу. Перевірити стан можна за адресами:

- `http://127.0.0.1:8080/health/live`
- `http://127.0.0.1:8080/health/ready` — перевіряє PostgreSQL і Redis.

Зупинити сервіси зі збереженням даних бази можна командою:

```sh
docker compose --env-file .env.example down
```

## Запуск прототипу інтерфейсу

Вимоги: Node.js 20.19+ або 22.12+ та npm.

```sh
npm ci
npm run dev
```

Vite виведе локальну адресу застосунку. Зараз він використовує вбудовані демонстраційні дані; ключ API не потрібен.

## Перевірки

Перевірки frontend:

```sh
npm run lint
npm run format:check
npm run test
npm run build
```

Перевірки Rust API:

```sh
cargo fmt --manifest-path apps/api/Cargo.toml --all -- --check
cargo clippy --manifest-path apps/api/Cargo.toml --all-targets --all-features -- -D warnings
cargo test --manifest-path apps/api/Cargo.toml --all-features
```

## Джерела даних і ліцензування

Синхронізація Bitcoin на запит отримує історію транзакцій із публічного API Blockstream Esplora. Ці дані описують транзакції, але не атрибутують особи й не забезпечують повного аналізу ризику гаманців. Санкційні набори та комерційні сервіси перевірки не підключені. Для майбутніх адаптерів потрібно документувати умови постачальника, покриття, частоту оновлення, правила атрибуції та обмеження на поширення даних. Для санкційного скринінгу варто використовувати офіційні машинозчитувані набори, якщо це дозволяють їхні умови. OFAC зазначає, що вебінструмент пошуку призначений для індивідуальних запитів, а не для постійних автоматичних перевірок ([FAQ OFAC](https://ofac.treasury.gov/faqs/287)). Комерційні аналітичні сервіси потребують окремої ліцензії.
