# Tracefold

Открытый инструмент для изучения потоков средств между блокчейн-адресами.

> **Статус проекта: ранний прототип.** Граф, подписи кошельков, транзакции, балансы и сигналы риска сейчас являются демонстрационными данными. Блокчейн-индексатор, санкционные источники и коммерческие сервисы проверки не подключены. Не используйте показанные значения для операционных или комплаенс-решений.

**Документация:** [Русский](README.ru.md) · [Українська](README.uk.md) · [English](README.md)

## О проекте

Tracefold задуман как OSINT-инструмент для расследований. Аналитик сможет начать с адреса, проследить переводы в поддерживаемых сетях, сохранить основания каждой связи и проверить сигналы риска. Алгоритмическая оценка не должна восприниматься как доказательство.

Прототип интерфейса включает граф потоков, фильтры сетей, таблицу последних переводов и объяснимый демонстрационный индекс риска.

## Принципы

- Для каждой находки показывать сеть, адрес, ссылку на транзакцию, источник и время наблюдения.
- Разделять наблюдаемые транзакции, пользовательские подписи и гипотезы аналитика.
- Показывать сеть как предположение, которое нужно подтвердить: адрес формата EVM может существовать в Ethereum, Base, Arbitrum и других совместимых сетях.
- Называть оценку индексом подверженности, а не вероятностью или доказательством нарушения.
- Показывать полноту покрытия и актуальность данных; не создавать впечатление, что отслеживаются все кошельки и сети.

## Планируемый стек

- **Frontend:** React, TypeScript, Vite, Tailwind CSS.
- **API и обработка:** Rust с Axum.
- **Постоянные данные:** PostgreSQL.
- **Кэш и краткосрочная координация:** Redis.

Backend, схема базы данных, адаптеры источников и production-модель риска ещё не готовы.

## Запуск прототипа интерфейса

Требования: Node.js 20.19+ или 22.12+ и npm.

```sh
npm ci
npm run dev
```

Vite выведет локальный адрес приложения. Сейчас оно использует встроенные демонстрационные данные; API-ключ не нужен.

## Проверки

```sh
npm run lint
npm run format:check
npm run build
```

Инструкции для Rust будут добавлены вместе с API.

## Источники данных и лицензирование

В прототипе нет сторонних атрибуций и санкционных данных. Для будущих адаптеров нужно документировать условия поставщика, покрытие, периодичность обновления, правила атрибуции и ограничения на распространение данных. Для санкционного скрининга следует использовать официальные машиночитаемые наборы, если это разрешают их условия. OFAC указывает, что веб-инструмент поиска предназначен для индивидуальных запросов, а не постоянных автоматических проверок ([FAQ OFAC](https://ofac.treasury.gov/faqs/287)). Коммерческие аналитические сервисы требуют отдельной лицензии.

## Безопасность и ответственное использование

Не отправляйте приватные ключи, seed-фразы и секреты. Tracefold задуман как watch-only инструмент. Сигналы риска помогают начать проверку, но не являются юридической консультацией, доказательством личности или автоматическим основанием для блокировки средств или отказа в обслуживании. Соблюдайте применимое законодательство и условия поставщиков данных.
