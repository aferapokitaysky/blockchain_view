# Історія Sui та покриття

Адаптер Sui запитує офіційний GraphQL mainnet (`https://graphql.mainnet.sui.io/graphql`) за адресою, на яку вплинула транзакція. Щоб використовувати іншого HTTPS GraphQL-провайдера, задай `SUI_GRAPHQL_URL`; якщо провайдер вимагає bearer token, вкажи `SUI_GRAPHQL_API_KEY`. Ці змінні читають backend API та sync worker. Спільний Redis gate витримує інтервал щонайменше 400 мс між запитами. Одна синхронізація обмежена трьома сторінками по 50 транзакцій, розмір відповіді — 4 МіБ.

Початкова синхронізація починається з найновіших проіндексованих транзакцій. Окремий історичний курсор завантажує попередні сторінки, поки курсор верхівки продовжує знаходити нові записи. Така схема не втрачає нові транзакції під час backfill. Покриття все одно обмежене індексацією та строком зберігання провайдера: публічна історія зазвичай доступна приблизно за останні 30–90 днів і не є архівом. Для глибшої історії потрібен архівний індексатор.

`balanceChangesJson` у Sui повідомляє підсумкові зміни балансу монет за власниками в транзакції. Адаптер зберігає лише підсумкову зміну відстежуваної адреси, залишаючи відправника й отримувача порожніми. Ненаправлений зв’язок `same_transaction` додається, лише якщо розібрано всі зміни й рівно у двох власників є ненульові рівні за модулем і протилежні зміни одного типу монети. Це свідчення збігу змін в одній транзакції; воно не доводить прямий платіж, володіння проміжними об’єктами чи продовження руху тих самих коштів. Такі зв’язки виключені з пошуку направлених шляхів та оцінки швидкого обігу. Невдалі транзакції пропускаються. Суми зберігаються в raw units, decimals монет не вгадуються.

Aptos і Sui використовують подібні hex-адреси акаунтів Move. Якщо формат неоднозначний, форма просить вибрати мережу. Hex-адреса довжиною 20 байтів також може бути адресою EVM, тому доступні всі три варіанти. Формат адреси не підтверджує активність акаунта.

Див. [Sui GraphQL API](https://docs.sui.io/develop/accessing-data/graphql/graphql-rpc), [запити GraphQL](https://docs.sui.io/develop/accessing-data/graphql/query-with-graphql) та [довідник Sui API](https://docs.sui.io/references/sui-api).
