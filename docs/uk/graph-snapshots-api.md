# API знімків графа розслідування

Дослідник графа використовує збережені спостереження одного розслідування. Спрямовані зв’язки будуються за подіями EVM, TRON, Solana, XRPL, TON та Aptos, у яких відомі відправник і отримувач. Cardano додає неорієнтовані свідчення участі в одній транзакції; це не перекази, і такі зв’язки не використовуються для пошуку спрямованих шляхів. Історія Bitcoin залишається у стрічці, але записи UTXO на рівні адреси не визначають контрагентів.

## Маршрути

`GET /api/v1/investigations/{investigation_id}/graph-snapshots` повертає останні 100 знімків.

`POST /api/v1/investigations/{investigation_id}/graph-snapshots` зберігає незмінне представлення графа та ID вихідних спостережень. API перевіряє, що кожне спостереження належить до цього розслідування.

```json
{
  "title": "Потік TRON",
  "focus_network": "tron",
  "focus_address": "TUoHaVjx7n5xz8LwPRDckgFrDWhMhuSuJM",
  "max_depth": 2,
  "source_transfer_ids": ["00000000-0000-4000-8000-000000000001"],
  "graph": {
    "nodes": [],
    "edges": [],
    "truncated": false,
    "sourceTransferIds": []
  }
}
```

Назва обмежена 120 символами, глибина — 1–3 переходами, кількість вихідних спостережень — 10 000 ID, розмір графа — 1 МіБ. Знімок зберігає показаний граф, навіть якщо пізніше завантажаться нові спостереження. Це фіксація зібраних даних, а не доказ безперервного руху коштів між переходами. API поки не має автентифікації та призначений для локальної розробки.
