# Політика безпеки

Tracefold працює в режимі спостереження: застосунок не запитує й не зберігає приватні ключі, seed-фрази або дані для підпису. Не додавайте такі секрети та реальні дані власників гаманців до звітів.

Інші мови: [English](../../SECURITY.md) · [Русский](../ru/security.md)

## Повідомлення про вразливість

Не публікуйте деталі, які можна використати для атаки, у відкритому issue чи pull request. Напишіть супроводжувачам приватно через [форму повідомлення про вразливість GitHub](https://github.com/aferapokitaysky/blockchain_view/security/advisories/new).

Вкажіть версію або commit, вплив, умови відтворення та можливе виправлення, якщо це безпечно. Звіти переглядають супроводжувачі проєкту; проєкт не гарантує строк відповіді й не пропонує винагороду за знайдені вразливості.

## Область і дані

Звіти можуть стосуватися API, фронтенду, sync worker, міграцій бази даних, конфігурації провайдерів і CI. Збій провайдера, непідтримувана історія мережі, хибне спрацювання евристики чи поведінка стороннього сервісу самі по собі не є вразливістю; це питання надійності або покриття, якщо вони не розкривають дані й не створюють шлях атаки.

Не надсилайте кошти та не використовуйте ключі або реальні транзакції для демонстрації проблеми. Використовуйте локальні тестові дані й приховуйте адреси гаманців, якщо вони не потрібні для відтворення.
