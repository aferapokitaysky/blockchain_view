# API снимков графа расследования

Исследователь графа использует сохранённые наблюдения одного расследования. Направленные связи строятся по событиям EVM, TRON, Solana, XRPL, TON и Aptos, где известны отправитель и получатель. Cardano и Sui добавляют ненаправленные свидетельства участия в одной транзакции; это не прямые переводы, и такие связи не используются для поиска направленных путей. Связь Sui требует полного набора ровно из двух равных по модулю и противоположных изменений баланса одного типа монеты. Это совпавшие изменения в транзакции, а не доказательство прямого платежа или движения тех же средств. История Bitcoin остаётся в ленте, но записи UTXO на уровне адреса не раскрывают контрагентов.

## Маршруты

`GET /api/v1/investigations/{investigation_id}/graph-snapshots` возвращает последние 100 снимков.

`POST /api/v1/investigations/{investigation_id}/graph-snapshots` сохраняет неизменяемое представление графа и ID исходных наблюдений. API проверяет, что каждое наблюдение относится к тому же расследованию.

```json
{
  "title": "Поток TRON",
  "focus_network": "tron",
  "focus_address": "TUoHaVjx7n5xz8LwPRDckgFrDWhMhuSuJM",
  "max_depth": 2,
  "source_transfer_ids": ["00000000-0000-4000-8000-000000000001"],
  "graph": {
    "nodes": [],
    "edges": [],
    "truncated": false,
    "sourceTransferIds": []
  }
}
```

Название ограничено 120 символами, глубина — 1–3 переходами, число исходных наблюдений — 10 000 ID, размер графа — 1 МиБ. Снимок сохраняет показанный граф, даже если позднее загрузятся новые наблюдения. Это фиксация собранных данных, а не доказательство непрерывного движения средств между переходами. API пока не имеет аутентификации и предназначен для локальной разработки.
