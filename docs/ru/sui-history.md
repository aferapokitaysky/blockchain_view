# История Sui и покрытие

Адаптер Sui запрашивает официальный GraphQL mainnet (`https://graphql.mainnet.sui.io/graphql`) по адресу, затронутому транзакцией. Чтобы использовать другой HTTPS GraphQL-провайдер, задай `SUI_GRAPHQL_URL`; если провайдер требует bearer token, укажи `SUI_GRAPHQL_API_KEY`. Эти переменные читает backend API и sync worker. Общий Redis gate выдерживает интервал не менее 400 мс между запросами. Одна синхронизация ограничена тремя страницами по 50 транзакций, размер ответа — 4 МиБ.

Первичная синхронизация начинается с самых новых проиндексированных транзакций. Отдельный исторический курсор загружает предыдущие страницы, пока курсор верхушки продолжает находить новые записи. Такая схема не теряет новые транзакции во время backfill. Покрытие всё равно ограничено индексацией и сроком хранения провайдера: публичная история обычно доступна примерно за последние 30–90 дней и не является архивом. Для более глубокой истории нужен архивный индексатор.

`balanceChangesJson` в Sui сообщает итоговые изменения баланса монет по владельцам в транзакции. Адаптер сохраняет только итоговое изменение отслеживаемого адреса, оставляя отправителя и получателя пустыми. Ненаправленная связь `same_transaction` добавляется, только если разобраны все изменения и ровно у двух владельцев есть ненулевые равные по модулю и противоположные изменения одного типа монеты. Это свидетельство совпавших изменений в одной транзакции; оно не доказывает прямой платёж, владение промежуточными объектами или продолжение движения тех же средств. Такие связи исключены из направленного поиска путей и оценки быстрого оборота. Неуспешные транзакции пропускаются. Суммы сохраняются в raw units, decimals монет не угадываются.

Aptos и Sui используют похожие hex-адреса аккаунтов Move. Если формат неоднозначен, форма просит выбрать сеть. Hex-адрес длиной 20 байт также может быть адресом EVM, поэтому доступны все три варианта. Формат адреса не подтверждает активность аккаунта.

См. [Sui GraphQL API](https://docs.sui.io/develop/accessing-data/graphql/graphql-rpc), [запросы GraphQL](https://docs.sui.io/develop/accessing-data/graphql/query-with-graphql) и [справочник Sui API](https://docs.sui.io/references/sui-api).
