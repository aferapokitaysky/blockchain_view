# История Aptos

В каталоге сетей Aptos использует официальный hosted Indexer GraphQL для mainnet. URL задаётся через `APTOS_INDEXER_URL` (по умолчанию `https://api.mainnet.aptoslabs.com/v1/graphql`). `APTOS_INDEXER_API_KEY` необязателен; если задан, он отправляется как bearer token. Адаптер ограничивает выборку 100 строками транзакций аккаунта и ответ 4 МиБ.

Связь `account_transactions` индексатора включает транзакции, взаимодействовавшие с аккаунтом. Затем адаптер получает Fungible Asset activity по версиям этих транзакций и сохраняет только явные события `Withdraw` и `Deposit`. Суммы остаются в целых raw units, поскольку decimals токена могут быть недоступны. Контрагент указывается только при единственной противоположной активности с той же версией транзакции, типом актива и суммой. Сложные Move-вызовы, NFT, legacy coin-события и неоднозначная активность нескольких сторон не объявляются прямыми переводами.

Адрес нормализуется к 32-байтовому hex в нижнем регистре с префиксом `0x`. Формат адреса позволяет распознать Aptos, но не подтверждает, что аккаунт активен. См. [документацию account transactions](https://aptos.dev/build/indexer/indexer-api/account-transactions) и [справочник схемы](https://aptos.dev/build/indexer/indexer-api/indexer-reference).
